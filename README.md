# Break Studio

Estudio para diseñar apps de menú por módulos para cafeterías y restaurantes. Incluye tres apps de ejemplo: Araucaria (elegante), Antojo (animada) y Casa Zócalo (cultural).

```bash
npm install
npm test          # compila y corre las pruebas
npm run demos     # genera las tres apps de ejemplo en dist/
```

Abre `dist/break-studio.html` en el navegador para usar el estudio (sin claude.ai guarda en el navegador y no descarga archivos).

Detalles de arquitectura y convenciones en `CLAUDE.md`.
